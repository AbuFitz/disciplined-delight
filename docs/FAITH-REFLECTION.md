# Faith & reflection

Faith data is optional, private by default, editable and removable. The app never infers religion from name, locale, ethnicity, diet or behaviour. A missing profile resolves to `not_for_me`; only an existing explicit legacy prayer opt-in migrates to Islam plus the prayer/remembrance practice.

The normalized model stores multiple selected traditions and separately selected capability packs: prayer/remembrance, reading, contemplation, fasting/dietary observance, sacred dates, weekly rest/worship, community/service, pilgrimage preparation and custom ritual. `not_for_me` or `prefer_not_to_say` always disables and clears practice packs. Islamic Salah UI and prayer reminders are gated by both Islam and prayer/remembrance; disabling that pack also turns off its reminder flag so a hidden schedule cannot keep firing. Selecting the broad module alone does not expose it.

This release provides the inclusive model, setup/settings controls and custom reflection path. Tradition-specific content, dates and calculation methods require qualified editorial review. The app must not fabricate dates, issue theological rulings or gamify observance. Social matching, leaderboards and advertising must never read this profile.
