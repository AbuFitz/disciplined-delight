## Usage audit (baseline for the migration)

- `<Panel>`: 79 uses across 21 files (train.build 9, circle*.crews 8, circle 8, today.tsx 8, circle*.four 7, circle\_.challenges 7, progress 6).
- Roundness introduced by the v3 pass: 171 `rounded-full`, 67 `rounded-2xl`, 32 `rounded-3xl` occurrences; 197 `border` mentions. All to be reduced to the 6/12/20 scale.
- Fixed/sticky layers: Shell header (sticky z-30), Shell bottom stack (fixed z-40), Buddy float (z-35), UpdateBanner (z-55), Sheet/Dialog (z-50), AlertDialog (z-60), Menu (z-70), skip link (z-80), onboarding action bar (sticky z-2). Planned: a single named z-scale in tokens.
- Bottom clearance: `--reserve-bottom` measured from the bottom stack (Shell), `pb-28` on `main`, Gym Mode uses `h-[calc(100dvh-var(--reserve-bottom)-3.6rem)]`, onboarding action bar uses its own safe-area padding.
- Domain logic and migrations are not touched by visual work.

## External-dependency blockers (not complete, by design)

- Supabase project and credentials (accounts, Circle, presence, server-side deletion).
- Spotify / Apple Music developer credentials and entitlements.
- Native wrapper / Health APIs / hardware for wearables and geofencing.
- Gym visual licence for production media.
